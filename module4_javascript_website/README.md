# Module 4 JavaScript Website — Hello & Goodbye

This project is based on the uploaded Module 4 Coding Assignment. The assignment asks you to loop through an array of names and print a greeting to the browser console:
- Names starting with **J** or **j** receive `Goodbye Name`.
- All other names receive `Hello Name`.

## Files
- `index.html` — page structure
- `style.css` — page styling
- `script.js` — greeting logic and console output

## How to run
1. Extract the ZIP file.
2. Open the `module4_javascript_website` folder.
3. Double-click `index.html` to open it in a browser.
4. Greeting results appear on the page and in the browser console.
5. To view the console in Chrome, press **F12** or **Ctrl + Shift + J**.

No installation or external libraries are required.

## Note
The uploaded assignment describes a JavaScript console exercise. This version keeps that required console output and adds a simple page interface to make the result easy to view.
